# UAI Sports Club Platform

A full-stack sports management and tournament intelligence platform for UAI Sports Club.

## Technology
- React and TypeScript
- Node.js and Express
- MongoDB and Mongoose
- JWT authentication

## Planned Features
- Sports, teams, tournaments and fixtures
- Match results and tournament leaderboard
- Student registrations and announcements
- Admin dashboard with role-based access

## Status
Project foundation and planning phase.

The university acronym must always be written as UAI.
